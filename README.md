# MiniMax 音色克隆工具

本地网页工具：克隆属于你自己的音色，然后用它持续合成语音。

- 界面：浏览器（启动后自动打开）
- 后端：Python 3 标准库，**零第三方依赖**，不需要 `pip install`
- 接口：MiniMax 开放平台 `https://api.minimax.cn`

---

## ⚠️ 开始之前必读

1. **本工具按量计费，直接扣除账户余额。** 每一次克隆、每一次合成、每一条试听都会产生费用。工具会在提交前显示字符数预估，但**最终费用以开放平台账单为准**。
2. **API Key 必须是「按量计费 API Key」，不是 M Plan 订阅 Key。** 两者相互独立、不能混用。获取入口：开放平台 → 账户管理 → 接口密钥。
3. **音色克隆要求账号已完成实名认证**（个人或企业），否则接口返回 `2038`。入口：开放平台 → 账户管理 → 账户信息。
4. **复刻得到的音色，7 天内没有正式调用会被系统删除。** 只要你正式合成过一次，音色即被激活、长期保留，台账会显示「此角色已入库」并不再倒计时；未使用过的才显示剩余天数并提醒你。

定价请以开放平台当前目录价为准，本文档不硬编码价格，避免过期误导：
<https://platform.minimaxi.com/docs/pricing/overview>

## 快速开始

### 1. 配置密钥

把 `.env.example` 复制为 `.env`，填入你的按量计费 API Key：

```
MINIMAX_API_KEY=你的真实密钥
```

`.env` 已在 `.gitignore` 中，不要提交，也不要把密钥贴进任何对话或代码。

### 2. 启动

```bash
python server.py
```

浏览器会自动打开 `http://127.0.0.1:8765/`。端口被占用时自动向后探测。

可选参数：

```bash
python server.py --port 9000     # 指定端口
python server.py --no-browser    # 不自动开浏览器
```

停止服务：`Ctrl + C`

## 录音 / 素材要求

### 待复刻音频（必填）

| 项 | 要求 |
| --- | --- |
| 格式 | `.mp3` / `.m4a` / `.wav` |
| 时长 | **10 秒 ~ 5 分钟** |
| 大小 | ≤ 20 MB |

**内容建议**：单人说话、无背景音乐、无混响、无明显混响或降噪痕迹。语速自然、音量稳定最理想。念一段完整的句子或短文比念单个字效果好得多。

### 示例音频（可选，强烈建议）

| 项 | 要求 |
| --- | --- |
| 格式 | `.mp3` / `.m4a` / `.wav` |
| 时长 | **< 8 秒** |
| 大小 | ≤ 20 MB |
| 附文 | 必须提供与音频**完全一致**的文本 |

提供示例音频能明显提升音色相似度与稳定性。

### 克隆日语音色

1. **素材本身必须是日语朗读** —— 这是相似度的根本前提，用中文素材克隆不出日语音色；
2. 把「语言增强 language_boost」选为 `Japanese`；
3. 日语与中文混说时选 `auto`，让模型自主判断；
4. 填写 `text_validation`（素材里实际念的日语文本），可以提前拦住文案不符的请求。

日语句子支持发音覆盖，例如 `20日/はつか`、`東京/トウキョウ`、`4桁/よんけた`。

## 界面怎么用

界面分两页。

### ① 克隆音色

1. 选待复刻音频 → **只在本机校验，不上传**（扩展名、大小；WAV 还会解析文件头读出时长）。不合规直接拦下，**不产生任何网络请求与费用**。点下方克隆按钮时才真正上传。
2. （可选）选示例音频 + 填它的准确文本 → 同样在点克隆按钮时才上传
3. 填 `voice_id`、选模型与语言增强、按需打开降噪 / 音量归一化 / AIGC 水印 / `text_validation`
4. 勾选声音授权确认
5. **选一个按钮：**

| 按钮 | 行为 | 费用 |
| --- | --- | --- |
| **仅克隆音色** | 不传试听文本，服务端不触发试听合成 | 不产生合成费用 |
| **克隆并试听** | 点一次展开试听文本框，填完再点一次提交，用新音色朗读 | 按试听字符数计费 |

两个按钮都会提交克隆，区别只在要不要合成试听音频。试听文本框里的字数会实时显示，并提示本次按多少字符计费。

### ② 音色合成

1. 从台账选择音色，已激活的显示「已入库」，未激活的显示剩余有效天数
2. 输入文本（实时显示计费字符数，超过 500 字符会二次确认）
3. 可调语速 / 音量 / 语调 / 情绪 / 输出格式 / 发音覆盖
4. 生成后可直接播放与下载，文件同时保存在 `data/output/`

## 可选参数说明

全部**默认关闭**，是否开启由你决定。

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `need_noise_reduction` | false | 降噪。素材环境嘈杂时开 |
| `need_volume_normalization` | false | 音量归一化。素材音量偏小时开 |
| `aigc_watermark` | false | 在音频末尾附加 AIGC 标识 |
| `text_validation` | 空 | 素材的预期文本，服务端做 ASR 相似度校验 |
| `accuracy` | 0.7 | 相似度阈值，低于该值返回 `1043` |
| `pronunciation_dict` | 空 | 「原文/替换内容」发音覆盖，支持日语假名 |

## 计费口径

**核对时间：2026-10-08。**
<https://platform.minimaxi.com/docs/guides/pricing-paygo>

### 单价

| 项目 | 单价 |
| --- | --- |
| 快速复刻（音色） | **¥9.90 / 音色** |
| 语音合成 `speech-2.8-hd` | ¥3.50 / 万字符 |
| 语音合成 `speech-2.8-turbo` | ¥2.00 / 万字符 |

**字符口径**：1 个汉字算 **2** 个字符；英文字母、希腊字母、标点符号、特殊符号、空格、回车各算 **1** 个字符。界面里的字符预估已按此口径实现，真实计费以服务端返回的 `usage_characters` 为准。

### 什么时候扣什么（实测确认）

| 路径 | 怎么操作 | 实际扣费 |
| --- | --- | --- |
| **仅克隆音色** | 克隆页点「仅克隆音色」 | **¥0**。克隆动作本身不收费 |
| **克隆并试听** | 克隆页点「克隆并试听」 | **只按试听文本的字符数计费**（几十字约 ¥0.02 ~ ¥0.35）。**不扣 ¥9.90** |
| **正式合成** | 合成页用该音色生成音频 | **首次生成时计入 ¥9.90 音色费** + 本次字符费；此后每次只计字符费 |

### 由此得出的三条结论

1. **试听不触发 ¥9.90。** 「克隆并试听」是安全的探路方式 —— 听完不满意就放着不管，最多损失几毛钱的试听费。
2. **¥9.90 只在你真的用这个音色生成音频时才扣。** 这一次合成同时也完成了音色保活（复刻音色 7 天内未调用会被删除）。
3. **「仅克隆音色」但从不合成 = 完全免费**，音色到期被删除也不会产生费用。

> 计费在服务端合成那一刻即发生，**与你对结果是否满意无关，也没有退款机制**。所以试听的价值就在于：用几毛钱先验证音色合不合心意，再决定要不要花 ¥9.90 真正启用它。

## 音色保存在哪里

**音色本体保存在 MiniMax 服务端，不在本机。**

克隆成功后，服务端就持有了这个 `voice_id`，之后的合成请求都是拿 `voice_id` 去找它。证据有两条：

- 官方「查询可用音色 ID」接口（`POST /v1/get_voice`）可以按 `voice_type: voice_cloning` 列出账号下全部克隆音色，含 `voice_id` 与创建日期
- 官方注明：**「快速复刻得到的音色为未激活状态，需正式调用一次才可在本接口查询到」** —— 与「首次正式合成才扣 ¥9.90」是同一件事

**本机的 `data/voices.json` 只是台账副本**，用于记录创建时间、7 天到期时间和使用次数：使用次数为 0 时显示倒计时，超过 0 就视为已激活、不再倒计时。删掉这个文件不会影响音色本身，但会丢失本地记录（音色仍在服务端，仍可继续使用）。

同理，`data/output/` 里存的是**生成出来的音频文件**，也不是音色。

## 常见错误码

| 状态码 | 界面提示含义 |
| --- | --- |
| `1002` | 触发限流，等约 1 分钟再手动重试 |
| `1004` | API Key 无效，检查 `.env` |
| `1008` | 账户余额不足，去开放平台充值 |
| `1013` | 服务端内部错误 |
| `1043` | 素材文本与 `text_validation` 不符 |
| `2013` | 音频格式 / 时长 / 大小不符 |
| `2038` | 无复刻权限，账号未实名认证 |

**所有失败都不会自动重试**，避免超时重发造成重复扣费。需要重试时由你手动点击。

## 安全说明

- 服务**只监听 `127.0.0.1`**，不对外网开放
- 校验 `Host` 与 `Origin`，阻断 DNS rebinding 与跨站调用
- API Key 只在服务端读取，永不下发浏览器、永不写入日志
- 页面不加载任何外部资源（无 CDN、无外链）
- 落盘文件名由服务端生成，`/audio/` 路径做了规范化校验

## 常见问题

**时长显示「未本地测量」**
说明 ffprobe 不在 PATH 中，只有扩展名和大小被本地校验，时长交给服务端校验。这是降级行为，不是缺陷。

**克隆成功但没有试听音频**
`voice_id` 已经存入台账不会丢，可在「② 音色合成」里补生成。

**台账文件坏了**
启动时会自动备份为 `data/voices.json.bak` 并以空台账启动，不会静默丢数据。

**端口全被占用**
用 `--port` 指定一个空闲端口。
